Frequently Asked Questions

Quick answers before you contact us.

Explore some common questions about the LIMBS platform and this frontend redesign.

What is LIMBS?

LIMBS stands for Legal Information Management and Briefing System. This project presents a modern frontend redesign of the platform.

Is this website connected to a backend?

No. This version focuses on frontend design, layout, responsiveness and user interaction.

Can I submit this form?

Yes. The form provides a frontend demonstration message, but it does not currently send data to a real server.

Is the website responsive?

Yes. The LIMBS redesign includes responsive layouts for desktop, tablet and mobile screens.
